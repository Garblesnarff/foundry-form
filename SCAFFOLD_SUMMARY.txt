================================================================================
ARCHITECTURE HIGHLIGHTS
================================================================================

1. LAYERED DESIGN
   - UI Layer: SwiftUI views (SessionView, HistoryView, etc.)
   - Detection Layer: PoseDetector (Vision + AVFoundation)
   - Analysis Layer: FormAnalyzer, AngleCalculator, RepCounter
   - Persistence Layer: DataStore (JSON/FileSystem)

2. OBSERVABLE PATTERN
   - PoseDetector publishes currentPose (19 landmarks)
   - FormAnalyzer publishes formScore (0-100%)
   - RepCounter publishes repCount
   - SwiftUI observes all changes in real-time

3. THREADING
   - Main Thread: All UI rendering
   - Session Queue: Camera lifecycle
   - Detection Queue: ML inference (Vision framework)
   - Proper async/await for responsive UI

4. PERFORMANCE TARGETS
   - Pose detection: 30fps (33ms per frame)
   - Form scoring: <50ms computation
   - Rep counting: <10ms state machine
   - Memory: <500MB peak
   - Battery: <5% drain per 30-min session
